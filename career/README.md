# Карьерный агент: методология и скиллы

Основа AI-агента для создания сильного резюме и системного поиска работы.
Состоит из трёх частей:

```
career/
├── methodology/     # база знаний: КАК делать хорошо (агент читает перед работой)
├── profile/         # данные о человеке: единый источник правды для всех артефактов
└── (скиллы)         # .claude/skills/* — конкретные умения агента
```

## Зачем это (JTBD)

Работы, на которые пользователь нанимает агента, — в `methodology/00-jtbd.md`:
главная работа, карта «когда/хочу/чтобы» с привязкой к скиллам и метрикам
успеха, эмоциональные работы и бэклог незакрытых. Любой новый скилл обязан
отвечать на вопрос «какую работу из карты он закрывает».

## Как это работает

Агент никогда не пишет резюме «из головы». Каждый скилл опирается на два источника:

1. **Методология** (`career/methodology/`) — проверяемые принципы: что делает резюме
   сильным, как работает ATS и hh.ru, как строить воронку поиска.
2. **Профиль** (`career/profile/profile.md`) — факты о человеке: опыт, достижения
   с цифрами, навыки, цели. Заполняется один раз через скилл `career-profile-intake`,
   дальше только обновляется.

Резюме = функция(профиль, вакансия, методология). Меняется вакансия — меняется
резюме, но факты всегда берутся из профиля, ничего не выдумывается.

## Скиллы

| Скилл | Что делает | Когда использовать |
|---|---|---|
| `career-profile-intake` | Интервью и сбор карьерного профиля (вход — свободный рассказ о треке) | Первый шаг, до любого резюме |
| `position-shortlist` | Кандидатные позиции из профиля → проверка рынком → шорт-лист 2–4 | После профиля, перед резюме; пересмотр — по данным воронки |
| `vacancy-analysis` | Разбор вакансии: требования, ключевые слова, матчинг с профилем | Перед адаптацией резюме под вакансию |
| `resume-build` | Создание/адаптация резюме (база или под вакансию) | Когда профиль заполнен |
| `resume-review` | Жёсткая оценка резюме по рубрике, адверсариальный ревью | После каждого черновика |
| `cover-letter` | Сопроводительное письмо / отклик под вакансию | Вместе с откликом |
| `job-search-strategy` | Стратегия поиска: каналы, воронка, план на неделю | В начале поиска и еженедельно |
| `outreach-message` | Аутрич: холодные письма, запрос рефералки, follow-up'ы, ответ на отказ | Нетворкинг и любой контакт с людьми в процессе поиска |
| `interview-prep` | Банк историй STAR+Reflection, подготовка и разбор интервью | С первого приглашения |
| `interview-coach` | Тренажёр: мок-интервью, дриллы, скоринг ответов, разбор транскриптов ([noamseg/interview-coach-skill](https://github.com/noamseg/interview-coach-skill), MIT) | Глубокая практика между interview-prep и реальным интервью |
| `offer-negotiation` | Оценка оффера (total comp), сравнение, контр-оффер | Вилка — до скринингов; остальное — при оффере |

## Порядок работы (happy path)

```
1. career-profile-intake  → рассказ о треке своими словами + вопросы агента
                            → career/profile/profile.md
2. position-shortlist     → кандидатные позиции → проверка рынком
                            → шорт-лист 2–4 позиций
3. resume-build × N       → мастер-резюме под каждую позицию шорт-листа
4. resume-review × N      → критика → правки → повторный ревью (до ≥ 85)
5. job-search-strategy    → каналы, недельный план, аудит находимости
6. По каждой вакансии:
   vacancy-analysis → resume-build (адаптация) → cover-letter → отклик
7. Еженедельно: job-search-strategy — разбор воронки, пересмотр шорт-листа
8. Пришло интервью: interview-prep (банк историй → подготовка → разбор после)
9. Пришёл оффер: offer-negotiation (оценка → контр-оффер → решение)
```

## Принципы (короткая версия)

- **Не выдумывать факты.** Всё в резюме должно прослеживаться до профиля.
  Нет данных — агент спрашивает, а не сочиняет.
- **Достижения, не обязанности.** Формула: действие → механизм → измеримый результат.
- **Одно резюме — одна цель.** Мастер-резюме под целевую роль, адаптации под вакансии.
- **Ревью отделён от написания.** Резюме проверяет «другой» агент по рубрике
  (`methodology/07-rubric.md`), как evaluator в оркестраторе этого репозитория.
- **Поиск работы — воронка с метриками**, а не рассылка вслепую.
- **Мы знаем, как работает другая сторона.** `methodology/08-recruiter-lens.md` —
  дистиллят инструментария рекрутеров ([awesome-recruitment](https://github.com/Sjamilla/awesome-recruitment)):
  как сорсеры ищут кандидатов и как быть находимым; `09-resources.md` —
  каталог внешних ресурсов (зарплаты, релокация, разведка компаний).
