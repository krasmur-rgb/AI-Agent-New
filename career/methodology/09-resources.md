# 09 · Каталог ресурсов для кандидата

Отобрано из [awesome-recruitment](https://github.com/Sjamilla/awesome-recruitment)
(инструментарий рекрутеров) — только то, что полезно стороне кандидата.
Список источника местами 2018–2020 годов; сюда взяты живые и устойчивые ресурсы,
перед использованием агент проверяет доступность. Скиллы ссылаются сюда,
когда нужны внешние данные.

## Зарплатная аналитика (калибровка вилки — до скрининга, см. 05/06)

| Ресурс | Что даёт |
|---|---|
| [levels.fyi](https://www.levels.fyi/) | Уровни и total comp по компаниям (BigTech, US-центрично) |
| [TechPays](https://techpays.eu/) | Открытые зарплаты в tech по Европе |
| [PayScale](https://www.payscale.com) / [Salary.com](https://salary.com/) | Общая зарплатная аналитика по ролям |
| [Glassdoor](https://www.glassdoor.com/) | Зарплаты + отзывы о процессе найма конкретной компании |
| [Progression.fyi](https://www.progression.fyi/) | Открытые карьерные фреймворки компаний — понять, что значит «senior» у них |
| Habr Career «Зарплаты» | Калибровка для рынка РФ (см. `04-market-ru.md`) |

## Правила использования

1. Ресурс — источник данных, не истина: зарплатные цифры сверять минимум
   по двум источникам, актуальность отзывов проверять по датам.
2. Мёртвые ссылки удалять из каталога, замены — добавлять (файл живой,
   как и источник-оригинал).
3. Инструменты сорсинга/скрейпинга из исходного списка сюда сознательно
   не переносились: кандидату они не нужны, а их «зеркало» описано
   в `08-recruiter-lens.md`.
