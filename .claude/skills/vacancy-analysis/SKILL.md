# Разбор вакансии и матчинг

Вход: текст или ссылка на вакансию. Опора: `career/profile/profile.md`
(если его нет — сначала `career-profile-intake`) и `career/methodology/06-job-search.md`
(раздел «Приоритизация вакансий»).

## Порядок

1. **Извлечь факты вакансии**: компания (+что о ней известно), роль, уровень,
   формат/гео, вилка (если есть), процесс найма (если описан).
2. **Разделить требования**: must-have vs nice-to-have. Маркеры must-have:
   «требуется», «required», повторение по тексту, положение в начале списка.
   Отделить реальные требования от HR-шума («динамичная команда»).
3. **Собрать словарь вакансии**: точные термины и формулировки, которыми
   работодатель называет навыки и задачи — это ключевые слова для ATS/фильтров
   и для адаптации резюме (`05-market-intl.md` про ATS, `04-market-ru.md` про hh).
4. **Скоринг матча** по профилю: для каждого must-have — закрыт ✓ / частично ~ /
   нет ✗, со ссылкой на факт профиля. Процент матча = закрытые must-have
   (частично = 0.5).
5. **Вердикт** по порогам методики: ≥ 70% — откликаться; 50–70% — только при
   высоком интересе и с сильным сопроводительным; < 50% — не откликаться
   (объяснить, чего не хватает, и что из этого добираемо).
6. **Если откликаемся** — выдать бриф для адаптации: топ-3 акцента вакансии,
   словарь (термины as-is), какие факты профиля подсветить первыми, какие
   пробелы закрыть в сопроводительном.

## Формат результата

```markdown
## {Компания} — {Роль}
Матч: {N}% · Интерес: {1–5, спросить у пользователя} · Вердикт: {apply / apply+letter / skip}
### Must-have
- {требование} — ✓/~/✗ {факт профиля или «нет»}
### Словарь вакансии
{термины через запятую, в формулировках работодателя}
### Бриф для адаптации
…
```

Результат сохранять в `career/search/vacancies/{компания}-{роль}.md` —
он понадобится resume-build и cover-letter.

## Правила

- Матч считать честно: натянутый матч = слитое время на интервью, где обман вскроется.
- «Не хватает X» — это и сигнал в профиль: возможно, X у человека есть, но не записан.
  Спросить, прежде чем ставить ✗.
