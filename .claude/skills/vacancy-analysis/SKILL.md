# Разбор вакансии и матчинг

Вход: текст или ссылка на вакансию. Опора: `career/profile/profile.md`
(если его нет — сначала `career-profile-intake`) и `career/methodology/06-job-search.md`
(раздел «Приоритизация вакансий»).

## Порядок

1. **Извлечь факты вакансии**: компания (+что о ней известно: стадия, размер,
   рынок — источники в `09-resources.md`, раздел «Разведка компании»), роль,
   уровень, формат/гео, вилка (если есть), процесс найма (если описан).
   Отметить **red flags**: недавние layoffs, высокая текучка (отзывы), размытое
   описание роли, «зарплата по итогам собеседования» + мутное equity,
   переопубликование вакансии месяцами.
2. **Разделить требования**: must-have vs nice-to-have. Маркеры must-have:
   «требуется», «required», повторение по тексту, положение в начале списка.
   Отделить реальные требования от HR-шума («динамичная команда»).
3. **Собрать словарь вакансии**: точные термины и формулировки, которыми
   работодатель называет навыки и задачи — это ключевые слова для ATS/фильтров
   и для адаптации резюме (`05-market-intl.md` про ATS, `04-market-ru.md` про hh).
4. **Скоринг матча** по профилю: для каждого must-have — закрыт ✓ / частично ~ /
   нет ✗, со ссылкой на факт профиля. Процент матча = закрытые must-have
   (частично = 0.5).
5. **Уровень и траектория**: эта роль для кандидата — рост (stretch), латераль
   или шаг назад? Что она даёт через 1–2 года (скоуп, трек IC/менеджмент)?
   Какой планки ждать на интервью (алгоритмы/систем-дизайн/кейсы — по уровню
   и типу роли)?
6. **Зарплатная разведка** (источники — `09-resources.md`): вилка по роли,
   уровню и гео; сравнение с ожиданиями из профиля. Расхождение вниз > 20% —
   фактор против отклика, зафиксировать до траты времени.
7. **Реферальный путь**: есть ли тёплый заход — знакомые в компании (1–2-я
   степень), общие сообщества? Тёплый заход всегда предпочтительнее холодного
   отклика (см. `06-job-search.md`, каналы).
8. **Вердикт** по порогам методики: ≥ 70% — откликаться; 50–70% — только при
   высоком интересе и с сильным сопроводительным; < 50% — не откликаться
   (объяснить, чего не хватает, и что из этого добираемо).
9. **Если откликаемся** — выдать бриф для адаптации: топ-3 акцента вакансии,
   словарь (термины as-is), какие факты профиля подсветить первыми, какие
   пробелы закрыть в сопроводительном, реферальный путь (если найден),
   5–7 вероятных вопросов интервью по стресс-точкам роли (вход для
   `interview-prep`).

## Формат результата

```markdown
## {Компания} — {Роль}
Матч: {N}% · Интерес: {1–5, спросить у пользователя} · Вердикт: {apply / apply+letter / skip}
Red flags: {список или «не найдены»}
Уровень: {stretch / lateral / step-back} · Вилка рынка: {данные + источник}
Реферальный путь: {есть: кто / нет}
### Must-have
- {требование} — ✓/~/✗ {факт профиля или «нет»}
### Словарь вакансии
{термины через запятую, в формулировках работодателя}
### Бриф для адаптации
…
### Вероятные вопросы интервью
1. …
```

Результат сохранять в `career/search/vacancies/{компания}-{роль}.md` —
он понадобится resume-build и cover-letter.

## Правила

- Матч считать честно: натянутый матч = слитое время на интервью, где обман вскроется.
- «Не хватает X» — это и сигнал в профиль: возможно, X у человека есть, но не записан.
  Спросить, прежде чем ставить ✗.
