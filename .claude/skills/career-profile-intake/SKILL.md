# Сбор карьерного профиля

Цель: заполнить `career/profile/profile.md` по шаблону `career/profile/TEMPLATE.md`.
Методика — `career/methodology/02-profile-intake.md`, прочитать перед началом.

## Порядок

1. Если `career/profile/profile.md` существует — прочитать и работать в режиме
   обновления: спрашивать только про пробелы и новое, не гонять человека по кругу.
   Если нет — создать из TEMPLATE.md и вести полное интервью.
2. Интервью вести **по одному блоку за раз**, в порядке из методики: цель →
   опыт (по каждому месту отдельно) → навыки → образование → артефакты →
   ограничения. Не вываливать анкету целиком.
3. В блоке опыта копать достижения вопросами из методики («что изменилось
   благодаря вам», «где цифры», «что используют до сих пор»). Довести каждое
   значимое место до ≥ 2 достижений или честной пометки «результата нет».
4. После каждого блока — записывать в profile.md сразу, показывая пользователю,
   что зафиксировано. Помечать уверенность фактов: ✓ точно / ~ оценка / ? не измерялось.
5. В конце: заполнить блок «Позиционирование» (по `01-pipeline.md`, этап 2),
   добавить запись в журнал обновлений, назвать оставшиеся пробелы.

## Правила

- Ничего не выдумывать и не «улучшать» факты. Нет данных — пробел с пометкой.
- Записи полные и сырые: сокращать будет resume-build, профиль — сырьё.
- Персональные данные — минимум (имя, город, контакты).
- Если пользователь принёс готовое резюме/профиль LinkedIn — распарсить его
  в профиль как черновик, затем интервью только по пробелам (особенно
  по достижениям: в старых резюме обычно обязанности).

## Критерий готовности

Профиль готов, когда: цель заполнена; у каждого значимого места работы ≥ 2
достижений с результатом или пометкой; навыки с уровнями. Об этом явно
сообщить и предложить следующий шаг: `position-shortlist` — выбрать позиции,
под которые делать резюме (позиционирование финализируется там).

Вход «свободный рассказ»: если пользователь начинает с описания карьерного
трека своими словами (текстом, голосом, потоком) — не перебивать анкетой:
распарсить рассказ в структуру профиля, показать, что понято, и дальше
задавать вопросы только по пробелам и достижениям.
