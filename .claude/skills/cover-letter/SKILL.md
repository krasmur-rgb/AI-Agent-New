# Сопроводительное письмо / отклик

Вход: бриф из vacancy-analysis (`career/search/vacancies/…`), адаптированное
резюме, профиль. Правила рынка: `04-market-ru.md` (короткий отклик на hh) /
`05-market-intl.md` (cover letter).

## Когда писать, а когда нет

Писать: требуется явно; вакансия из топа по интересу; надо объяснить неочевидное
(смена области/страны, перерыв, оверквалификация); матч 50–70% и письмо — способ
закрыть пробелы. Не писать: веерные отклики с высоким матчем, где письмо будет
генерическим — генерическое письмо хуже отсутствия письма.

## Структура

**hh.ru (3–6 предложений в поле отклика):**
почему эта вакансия/компания (1 предложение, конкретное) → 2–3 факта под их
ключевые требования (с цифрами, из адаптированного резюме) → готовность к
следующему шагу. Без «Здравствуйте, меня заинтересовала ваша вакансия» в качестве
содержимого — это нулевая информация.

**Международный cover letter (3 абзаца, ≤ полстраницы):**

1. Хук: почему именно эта компания — конкретный факт о них (продукт, релиз,
   инженерный блог), связанный с опытом кандидата. Не лесть, а связь.
2. Доказательства: 2–3 достижения, закрывающие топ-акценты вакансии из брифа.
   Не пересказ резюме, а прицельный выбор под их боль.
3. Закрытие: что кандидат хочет делать у них + следующий шаг. Тон уверенный,
   без «I hope» и извинений.

## Правила

- **Каждый факт — из профиля/резюме.** Письмо не место для новых подвигов.
- Конкретика про компанию обязательна: если письмо подходит любой компании
  после замены названия — оно не готово.
- Зеркалить словарь вакансии (термины из брифа).
- Длина: hh — до 120 слов; intl — 150–250 слов. Длиннее не читают.
- Пробел из вакансии (✗ в матче) можно адресовать прямо: одной честной фразой
  «X не использовал, но Y — смежный опыт + скорость освоения показана там-то».
  Не оправдываться дольше одного предложения.
- Сохранять в `career/search/letters/{компания}-{роль}.md`, отметить в логе
  откликов.
