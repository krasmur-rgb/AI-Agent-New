# Создание и адаптация резюме

Перед работой прочитать: `career/methodology/03-resume-principles.md` (ядро),
плюс модуль целевого рынка — `04-market-ru.md` и/или `05-market-intl.md`.
Источник фактов — ТОЛЬКО `career/profile/profile.md`.

## Два режима

**Мастер-резюме** (под позицию из шорт-листа в профиле, блок «Позиционирование»;
шорт-листа нет → сначала `position-shortlist`. Позиций несколько — по мастеру
на каждую, из одного профиля; противоречия фактов между мастерами — блокер):

1. Отобрать из профиля факты, релевантные роли; нерелевантное — сжать или убрать.
2. Переписать достижения в буллеты по формуле: глагол действия → механизм →
   измеримый результат. Сильнейшие — первыми в каждом месте.
3. Собрать структуру по ядру методики: шапка → summary → опыт → навыки →
   образование. Summary писать последним.
4. Применить правила рынка (RU: фото/зарплата/название под hh; intl: без
   персональных данных, ATS-верстка, стандартные названия должностей).
5. Сохранить в `career/resumes/master-{роль}.md` (+ версия на английском
   отдельным файлом, если рынок «оба»).
6. Прогнать через `resume-review`; править до вердикта ship (≥ 85, без блокеров).

**Адаптация под вакансию** (вход — бриф из vacancy-analysis):

1. Взять мастер-резюме как основу — не писать с нуля.
2. Переранжировать буллеты и навыки под топ-3 акцента вакансии.
3. Переписать формулировки в словарь вакансии (терминами работодателя),
   не меняя фактов.
4. Убрать нерелевантное этой вакансии; название резюме/целевая роль — как в вакансии.
5. Сохранить в `career/resumes/tailored/{компания}-{роль}.md` и отметить
   версию в логе откликов (`career/search/applications.md`).

## Жёсткие правила

- **Каждый факт прослеживается до профиля.** Хочется добавить то, чего в профиле
  нет — остановиться и спросить пользователя; если правда — сначала в профиль.
- Ни одного «отвечал за / занимался / участвовал» в буллетах.
- Цифра или масштаб минимум в 60% буллетов; честные оценки помечены в профиле.
- 1–2 страницы; markdown-версия — источник, экспорт в PDF — отдельным шагом
  по правилам рынка (для intl — одноколоночный ATS-safe шаблон).
- Черновик не отдаётся пользователю как готовый: сначала resume-review.
