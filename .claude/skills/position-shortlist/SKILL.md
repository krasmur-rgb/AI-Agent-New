# Шорт-лист позиций

Закрывает работу «выбрать, куда подаваться» (`00-jtbd.md`). Методика —
`career/methodology/13-position-shortlist.md`. Вход — заполненный
`career/profile/profile.md` (нет профиля → сначала `career-profile-intake`).

## Порядок

1. **Сгенерировать 5–8 кандидатных позиций** из фактов профиля по трём линиям
   (прямое продолжение, смежные, нишевые комбинации). К каждой — обоснование:
   какие достижения дают право. Показать пользователю ДО проверки рынком —
   он может сразу отсечь неинтересное и добавить свою гипотезу.
2. **Проверить рынком** оставшиеся: по 3–5 реальных свежих вакансий на позицию
   (WebSearch/WebFetch по hh, LinkedIn, бордам; если поиск недоступен —
   попросить пользователя накидать ссылки). Посчитать усреднённый матч
   must-have × профиль, объём рынка, вилку (`09-resources.md`).
3. **Показать таблицу**: позиция · матч · объём рынка · вилка · обоснование.
   Спросить интерес (1–5) по каждой.
4. **Согласовать шорт-лист 2–4** по правилам методики (матч ≥ 60%, живой
   рынок, интерес ≥ 3; позиция-мечта 50–60% — допустима с оговоркой).
   Записать в профиль, блок «Позиционирование»: позиции с обоснованиями
   и опорными достижениями.
5. **Запустить производство резюме**: по каждой позиции шорт-листа —
   `resume-build` (мастер) → `resume-review` до ship. Напомнить инвариант:
   один профиль — источник всех резюме; противоречия фактов между резюме —
   блокер.
6. Предложить следующий шаг: `job-search-strategy` (каналы и недельный план
   уже под конкретные позиции).

## Режим пересмотра

Вход — данные еженедельного разбора: позиция без вакансий 2+ недели или
с конверсией заметно ниже остальных → предложить замену из списка шага 1,
пересчитать рынок, обновить профиль и создать/архивировать мастер-резюме.

## Правила

- Кандидатная позиция без опоры на факты профиля не предлагается.
- Матч считать честно — завышенный матч обнаружится на скрининге и сожжёт время.
- Не превышать 4 позиции, даже если «всё интересно»: распыление — главный
  враг конверсии.
- Интерес пользователя — спросить, не предполагать.
