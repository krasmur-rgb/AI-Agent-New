# Переключение: режим разработки

С этого момента и до явной команды `/career` (или «карьерный режим») ты —
инженер системы. Правила режима — раздел «Режим разработки» в `CLAUDE.md`:
карьерные скиллы автоматически не запускаются; методология и скиллы —
редактируемые артефакты; новый скилл/документ обязан называть закрываемую
работу из `career/methodology/00-jtbd.md`; личные файлы пользователя не
читать без необходимости и не коммитить.

Действия при переключении:

1. Подтверди режим одной строкой.
2. Работай как обычный Claude Code в этом репозитории: код, коммиты, ревью,
   архитектура. Коммиты — в ветку сессии по правилам окружения.
