# Аутрич-сообщения

Методика — `career/methodology/12-outreach.md` (анатомия, сценарии стадий,
тайминги, лимиты платформ). Факты — только из `career/profile/profile.md`;
контекст вакансии/компании — из `career/search/vacancies/…` (если есть —
иначе сначала `vacancy-analysis` или спросить детали).

## Порядок

1. **Определить сценарий и уместность**: стадия (до отклика / после отклика /
   после отказа), адресат (рекрутер / нанимающий менеджер / знакомый /
   сотрудник компании), платформа. Сверить тайминг с методикой (follow-up
   отклика — 7–14 дней, после интервью — 3–5) и с логом: не превышен ли лимит
   follow-up'ов по этой вакансии.
2. **Собрать хук**: найти персональную зацепку под адресата (пост, доклад,
   продукт команды, общий контекст). Нет зацепки — честно сказать пользователю
   и предложить, где искать (`09-resources.md`, раздел «Разведка»); писать
   без хука — нельзя.
3. **Подобрать доказательства**: 1–3 факта из профиля под боль адресата,
   с цифрами.
4. **Сформулировать один аск** — конкретный и лёгкий для адресата.
5. **Написать по анатомии** (хук → доказательства → аск → лёгкий выход),
   в тоне и лимитах платформы. Для рефералки — приложить черновик «почему я»,
   снимающий работу с реферера.
6. **Показать пользователю** — отправляет человек, не агент. По желанию дать
   2 варианта тона (суше/теплее).
7. **Записать в лог** (`career/search/applications.md`, канал `outreach`):
   кому, когда, сценарий, вакансия; поставить дату следующего шага.

## Правила

- Ни одного факта вне профиля; никакой лести и «всю жизнь мечтал(а) у вас
  работать» — только конкретная связь.
- Один аск на сообщение. Прямые ссылки, без сокращателей.
- Ответ на отказ — всегда: благодарность → запрос фидбэка → «держите в уме».
  Полученный фидбэк → в лог и в разбор воронки (`job-search-strategy`).
- Персонализация не масштабируется веером — и не должна: 3–5 качественных
  нетворкинг-действий в неделю по плану из `06-job-search.md`.
- Для глубокой проработки кампании нетворкинга (последовательности, мульти-
  канальность) — команда `outreach` скилла `interview-coach` как второе мнение.
