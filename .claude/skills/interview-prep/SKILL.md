# Подготовка к интервью

Методика — `career/methodology/10-interview-prep.md`. Источники:
`career/profile/profile.md` (факты), разбор вакансии из
`career/search/vacancies/…` (вероятные вопросы, планка, профиль компании).
Рабочий файл — `career/interview/story-bank.md`.

Для глубокой тренировки — мок-интервью по форматам, дрилл-прогрессия, разбор
реальных транскриптов со скорингом, отслеживание прогресса — использовать
скилл `interview-coach` (его раздел Project Integration описывает стыковку:
общий профиль, общий story bank, состояние в `career/interview/`).

## Режим 1: построить/пополнить Story Bank

1. Прочитать профиль; каждое достижение с контекстом — кандидат в историю.
2. Развернуть 5–10 сильнейших в STAR+Reflection. Reflection обязательна —
   выжать из пользователя «чему научился, где применил снова» вопросами,
   это не выдумывается.
3. Разметить тегами компетенций (конфликт, провал, лидерство, приоритизация,
   влияние без полномочий, инициатива, сложное решение, неопределённость,
   менторство). Построить матрицу покрытия; обязательно 1–2 честные провальные
   истории.
4. Дыры покрытия → доспросить пользователя (возможно, факт есть, но не в
   профиле — тогда сначала в профиль, потом история).

## Режим 2: подготовка к конкретному интервью

1. Вход: компания, этап (HR / hiring manager / панель / финал), вероятные
   вопросы из разбора вакансии. Разбора нет — сначала `vacancy-analysis`.
2. Подобрать истории под вопросы; показать пользователю карту
   «вопрос → история → на что сделать упор».
3. Отрепетировать «рассказ о себе» (60–90 сек, из позиционирования) —
   написать текст, прогнать с пользователем.
4. Подготовить 3–5 вопросов работодателю (профиль успеха роли, команда, планка).
5. По запросу — мок-интервью: агент играет интервьюера, задаёт вопросы
   (включая уточняющие «а что сделали именно вы?»), после — разбор по гигиене
   ответов из методики.

## Режим 3: разбор после интервью

1. Записать в лог откликов: какие вопросы были, что зашло/не зашло, следующий шаг.
2. Прозвучавшие вопросы → пополнить предсказания в разборе вакансии;
   слабые истории → доработать в банке.
3. Новые факты, всплывшие в рассказах пользователя, — в профиль.

## Правила

- История строится только на фактах профиля; натяжка вскрывается уточняющими
  вопросами интервьюера.
- Личный вклад отделять от командного в каждой истории.
- Story Bank — живой файл: после каждого интервью он становится лучше.
